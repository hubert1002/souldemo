星语 「灵魂社交」
聊天 App 原型

以「人格匹配 + 弱颜值」为核心的陌生人社交。用契合度降低开场成本，用共聊任务把一次性匹配变成长关系。

核心路径

  1. 星球首页：用「灵魂浓度 / 在线同频人数」制造稀缺感
  2. 灵魂匹配：扫描动画 → 契合度卡片 → 一键打招呼
  3. 进入聊天：系统破冰话题 + 灵魂问答，前 3 句零压力
  4. 心动值养成：每轮对话积累心动值，点亮「灵魂伴侣」
  5. 回流：广场瞬间 / 群聊派对，给沉默关系制造话题钩子
  6. 关系沉淀：好友列表按灵魂伴侣 / 密友分组，资料页补全信任，设置页承接基础配置
  7. 关系维护：申请通过 → 打招呼 → 资料编辑 / 瞬间互动，举报与拉黑兜底安全

可点击的关键交互

  • 灵魂匹配：扫描计数 → 契合度分数滚动 → 打招呼直达聊天
  • 聊天：发消息会触发「正在输入」与拟真回复；点语音条有波形播放；灵魂问答可作答并加心动值
  • 好友：消息页「全部」/ 我的「密友关系」进入；支持搜索、按关系筛选，点行进资料页
  • 资料与申请：资料页「⋯」可举报 / 拉黑；好友申请可同意、忽略或直接打招呼
  • 个人与瞬间：我的「✎」编辑头像 / 昵称 / 签名 / 标签；瞬间支持九宫格放大、点赞与评论
  • 广场 / 设置：点赞有回弹与计数；设置项开关、清缓存、退出登录均有反馈

要验证的指标

>38%匹配→打招呼转化
>55%首条消息 24h 回复率
>3.2 轮单会话日均对话轮次
>12%7 日双边留存

原型为纯前端演示，数据为模拟值。建议在 390×844 的手机视口中查看。
